# Product Hunter Pro v23 — Commercial Experience Patch

This release focuses on purchase-quality presentation, predictable dark/light modes, and faster professional navigation.

## Highlights

- Full contrast-safe light and dark themes across text, captions, forms, tabs, popovers, expanders, metrics, and tables.
- New application shell with brand mark, service state, version, and quick-navigation hint.
- More Microsoft/Adobe-like visual tokens: Segoe typography, restrained shadows, square controls, dense enterprise tables, and clearer hierarchy.
- Quick Navigation panel in the sidebar.
- Research summary KPIs and a highlighted top-evidence card.
- Responsive layout improvements for narrower screens.
- Updated version labeling throughout the primary workspaces.

## Deployment

Upload every file in this folder to the root of the existing `item-tracker1` repository, replace older files, commit, and reboot Streamlit. Existing secrets remain unchanged.

# Upgrade to Product Hunter Pro v5

Version 5 adds the Best Match engine.

## New features

- Scores every retailer listing from 0–100 against the requested specification.
- Compares manufacturer, exact model number, model family, dimensions, materials, finish, connections, and accessories.
- Ranks the strongest listing first for every search term.
- Shows why a listing differs and what details are missing.
- Adds Best Match, Match Score, Match Grade, Exact Model, Matched Features, Missing Features, Differences, and Recommendation fields.
- Adds a dedicated **Best Matches** worksheet.
- Highlights strong, review-required, and poor matches in Excel.

## Deploy

1. Extract the ZIP.
2. Upload all files and folders to the root of your existing GitHub repository, replacing older files.
3. Commit the changes.
4. In Streamlit Community Cloud, open **Manage app** and reboot.
5. Run a new product search. Existing saved Excel workbooks will not be modified automatically.

Match scores are procurement aids, not manufacturer approvals. Verify the official product data and exact configuration before ordering.

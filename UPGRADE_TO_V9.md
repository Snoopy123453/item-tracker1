# Product Hunter Pro v9

Adds **Exact Product From Image** workspace.

- Upload up to four views of the same product.
- Reads visible logos, labels, model numbers, MPNs, UPC text, variant details, and packaging.
- Builds exact-identifier-first retailer searches.
- Compares the uploaded reference image against candidate retailer images.
- Reports Exact, Probable, Similar, Different, or Unclear with a visual score and differences.
- Does not claim an exact match unless visual evidence is strong.

Upload all files to the GitHub repository root, replace older files, commit, and reboot Streamlit.

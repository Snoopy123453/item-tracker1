# Upgrade to Product Hunter Pro v11

## New: Official Manufacturer Search

Product Search can now search official manufacturer websites and product catalogs in addition to retailer marketplaces.

### Included

- New sidebar option: **Official manufacturer websites and product catalogs**
- Manufacturer pages are ranked above marketplaces.
- Exact model-number mentions are flagged.
- Results identify likely official sources, source domain, page type, and confidence.
- Manufacturer links appear in a dedicated app table.
- Excel reports now include a **Manufacturer Sources** worksheet.
- Marketplace domains are excluded from this manufacturer-only result set.

### Update Streamlit

1. Extract this ZIP.
2. Upload all files to the root of the existing GitHub repository.
3. Replace the older files and commit the changes.
4. Reboot the Streamlit app.

The existing SerpApi key powers this feature. No additional API key is required.

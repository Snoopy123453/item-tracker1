# Product Hunter Pro v31 — Enterprise UI + RFQ & Quote Center

## Main changes
- New **RFQ & Quote Center** workspace.
- Create RFQs from project workbooks or manual line items.
- Import multiple vendor CSV/XLSX quotes.
- Normalize vendor, model, quantity, pricing, freight, tax, stock, lead time, and substitutions.
- Compare total landed cost, coverage, lead time, and exceptions.
- Generate a decision-support vendor recommendation.
- Export a professional Excel bid tab.
- Added a ribbon-style commercial interface surface.

## Deployment
Upload all files to the root of `item-tracker1`, replace existing files, commit, and reboot Streamlit. No secret changes are required.

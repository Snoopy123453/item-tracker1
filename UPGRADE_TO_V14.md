# Product Hunter Pro V14 - Fixture Package Builder

## Added

- New **Package Builder** workspace.
- Built-in S-1 complete sink package with six specified manufacturer components.
- Custom package entry using `Component | Manufacturer | Model | Description | Qty`.
- Editable supplier, unit price, stock status, lead time, quote number, and product-link fields.
- Package total calculation and vendor quote-return worksheet.
- RFQ-ready component rows that retain the parent fixture item tag.
- Automated tests for recognition, quantity scaling, and workbook output.
